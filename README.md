# James Shedden live wallpapers

The 21 animated artworks from <https://www.james.sh/gallery>, converted
to iPhone wallpaper clips: 1290x2796 portrait, H.264 `.mp4`, 30 fps, no
audio, 3-6 s (short loops are repeated whole so they stay seamless).

- `wallpapers/crop/` - full-bleed, cropped to portrait around the subject
- `wallpapers/fit/` - the whole artwork on a blurred copy of itself
- `make_wallpapers.sh` - re-downloads and rebuilds everything
  (`W=1179 H=2556 bash make_wallpapers.sh` for non-Max phones; edit the
  per-clip focus values in `CLIPS` to move a crop left/right)

Artwork is by James Shedden; these are for personal use only.
